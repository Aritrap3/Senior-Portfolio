About Me

I'm Aritra Paul, a senior at Thomas A. Edison CTE High School. I've been learning to code since 10th grade, and I'm passionate about using technology to create fun experiences.

My career goal is to become a game developer or software engineer. I want to use Unity and C# to build games that are fun and tell real stories.

The skills I've built so far include Python, HTML, CSS, Unity, and Figma. I'm always looking for ways to improve and learn something new — whether that's a new tool, a new language, or a better way to solve a problem I've already faced.

Projects

01
Unity · C# · Game for Change

Rainforest Cure

A game for social change. The player runs through a rainforest collecting gems that represent the forest's health. The goal is to restore the rainforest to full health before time runs out. Built entirely in Unity with C# scripting.

Reflection: This was my most ambitious project so far. I learned how to use Unity's physics system, write collision detection in C#, and design a level that actually teaches the player about environmental issues. The biggest challenge was balancing the gameplay — making it fun but also keeping the message clear. If I were to improve it, I would add more levels and a story cutscene at the end.

Python · CodeSkulptor3

Holiday Art Project

An interactive visual art piece built with Python in CodeSkulptor3. This was one of my first creative coding projects, using shapes, colors, and simple animation to create a holiday-themed scene through code alone.

03
Python · CodeSkulptor3

The Math Challenge

A simple interactive tool that anyone can use to sharpen their math skills. It tests the user on addition, subtraction, multiplication, and division — keeping things clean and straightforward so the focus stays on practicing. Built with Python in CodeSkulptor3.

Reflection: This project was about building something actually useful. I had to think about how the program should respond to correct and incorrect answers, how to keep score, and how to make the experience feel fair to the user. It taught me how to use conditionals and loops in a practical way — not just as exercises, but as real logic that controls what a program does. It's simple, but it works, and I'm proud of that.

Competitions & Challenges

G4C

Games for Change

Submitted Rainforest Cure to the Games for Change student challenge. The competition challenges students to create games that address real-world social issues. My entry focused on environmental conservation and the importance of protecting rainforests.

What I learned: Competing in G4C taught me how to pitch a game with a clear message. I had to think beyond just "is this fun?" and ask "does this actually say something?" That shift in thinking has changed how I approach every project now.

INFY

Infy App Design Challenge

Competed in the InfyAPP Challenge, run by Infosys Foundation USA at Thomas A. Edison CTE High School. Students build working apps designed to improve New Yorkers' lives, mentored by Infosys volunteers and judged by a panel of industry professionals. My team made it to the semi-finals.

What I learned: Getting to the semi-finals showed me that my work could hold up against real competition. The challenge pushed me to think about who I was building for — not just what the app does, but why someone would actually need it. It was my first time designing with a real user in mind, and that changed how I think about every project since.

CAC

Congressional App Challenge

The Congressional App Challenge was a competition where I worked with my team to design and create a prototype for an app called Ecolink. The app allows people to report problems in their communities, such as illegal dumping or other local issues, so that other community members can see the reports and help fix those problems. Through this project, I got to work with a team and develop an idea that could make a positive difference in my community.

What I learned: I learned how to work with a team, think about problems in my community, and turn an idea into an app prototype. This project also showed me how technology can help people share local concerns and work toward solutions.
